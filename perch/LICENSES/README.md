# LICENSES/ — licence texts a redistribution of the perch keeps

One file per licence text the perch's third-party code needs shipped with it, named by its SPDX id. [`../THIRD-PARTY.md`](../THIRD-PARTY.md)
says which dependency each belongs to, and why.

| File | For |
|---|---|
| `Apache-2.0.txt` | `alacritty_terminal` 0.26.0 (Apache-2.0 only): the `LICENSE-APACHE` that ships in its crate, copied byte for byte |

The perch's own licence (MIT) is the one in `Cargo.toml`; `portable-pty`'s MIT text is short enough to sit in `THIRD-PARTY.md` itself.
