no extensions on this box

An extension is a directory in C:\Users\dxcen\AppData\Roaming\eidolon\extensions with an extension.rn in it: a namespaced bundle of Rune tools, optionally served by a long-running process of its own.

Nothing is discovered automatically and nothing is loaded until config.toml names it — opt-in, because an extension may bring a process up. Write one.

stopping a shared service

jev's service is up on :63388 and is machine-scoped — every open session is using this one copy. Disabling it stops the process now, and the next call from any chat fails until something starts it again.
