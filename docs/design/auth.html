harness extensions credentials

This page can say whether a key is here and when it was last written. It cannot say what it is. Nothing on this page, and no route in eidolon, returns a stored value.

A key goes in through a POST body and nowhere else — never a URL, never a command line, never a log. The store's one door out is a Rust call, taken by the one consumer that has to set a header. The other door is eidolon secret set NAME < key.txt, which reads stdin for the same reason. Store: C:\Users\dxcen\AppData\Roaming\eidolon\secrets

An expired access token is not an expired login: the refresh token in this file mints a new one on the next turn. The only real expiry is a refresh token that has been revoked, and nothing local can know that — the first request to use it finds out. deleting a key

Deleting brave_search removes the search tool from every new session — the key is the capability, so there is no degraded search, only none. The value cannot be recovered from here or from anywhere; you will need the key again to put it back.
