# Open WebUI skin (retired)

Retired 2026-09-26. Replaced by `webui/term/`.

## What this was

Minerva's face used to be a stock Open WebUI install (`uv tool install
open-webui`), re-skinned and patched on every launch by `hoot webui` /
`hoot up` (`Set-WebuiEnv` in `bin/hoot.ps1`):

| file | role |
|---|---|
| `custom.css` | the skin, copied into Open WebUI's `/static/custom.css` hook |
| `loader.js` | runtime icon swap + eidolon nav rows; generated by `build-loader.py` |
| `build-icons.py`, `build-loader.py` | generators, fed by `owui-icons.json`, `icon-map-full.json`, `dinkie-bodies.json` |
| `brand/` | the owl in every brand slot Open WebUI reads |
| `workspace.js`, `workspace.css`, `graph-adapter.js` | the workspace panel and jev graph view |
| `minerva_credentials.py`, `minerva_workspace.py`, `minerva_catalog.py` | FastAPI routers hoot copied into the installed package and wired into its `main.py` |
| `test_*.py`, `tests/` | unit tests for the routers and `workspace.js` helpers |
| `README-icons.md` | the icon-mapping notes |

## Why it was retired

- It patched a third-party package in place (`main.py`, `env.py`,
  `index.html`), so every `uv tool upgrade open-webui` could break it.
- It needed eidolon's OpenAI shim on native Windows; eidolon now runs in
  WSL only (upstream is unix-only).
- `webui/term/` is the replacement face, served by `eidolon web` from WSL
  (see `webui/term/README.md`).

Kept for history and reference only. Nothing in the repo loads these files.
The shared owl source, `webui/owl-green.svg`, stays in `webui/` because
`webui/term/` copies it.
